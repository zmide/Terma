Terma · 把远程工作区装进 NAS
SSH · SFTP · 本地文件 · noVNC · 端口转发

打开浏览器，连接服务器、处理文件、访问远程桌面。电脑、平板和手机共用保存在 NAS 上的连接配置，随时接着工作。

Your remote workspace, served by your NAS. Connect, transfer files and access VNC desktops from a browser.

01 / 连接与终端

按分组整理 SSH 连接，在标签页与分屏之间切换。终端支持命令片段、快捷键与会话保活，常用端口转发也能集中管理。

SSH terminals, workspace tabs, command snippets and tunnels.

02 / 文件管理与传输

通过 SFTP 浏览、上传、下载和编辑远端文件。“本地文件”标签可选择浏览器授权的电脑文件夹或应用中心授权的 NAS 目录，与远端分屏互传。同名文件可选择覆盖或重命名，任务完成后自动刷新目录。

SFTP and local file tabs, text editing, transfer progress and overwrite or rename choices.

03 / 手机也能顺手操作

返回按钮旁就能切换已打开的标签，点“×”关闭会话。紧凑工具栏、底部快捷键和命令输入框，让小屏幕也能处理终端与文件任务。

Switch and close tabs, use terminal shortcuts and browse SFTP files on a phone.

04 / 浏览器中的 VNC 远程桌面

内置 noVNC，可直接查看和操作远程桌面，无需在 NAS 上另装图形客户端。目标设备需运行 VNC 服务，连接与会话都在 Terma 中管理。

Bundled noVNC opens remote desktops in browser tabs. The remote device needs a VNC server.

开始使用

  1. 设置密码：安装时两次输入至少 12 个字符的独立 Web 密码，无需用户名。
  2. 打开应用：从飞牛桌面进入，或使用 NAS 的 8088 端口访问。
  3. 配置与升级：密码、监听地址和域名在“应用中心 → Terma → 应用设置”调整。“设置 → 关于”可检查版本、查看更新日志并下载匹配架构的 FPK，再通过应用中心手动升级。

Set a separate Web password during installation. Open port 8088, manage password and network settings in App Center, and check versions and release notes in Terma Settings → About.

使用范围
所有访问均需登录，使用同一个 Terma 实例。电脑目录受浏览器授权与安全上下文限制，NAS 目录受应用中心授权限制。此包提供后台 Web 功能，不包含原生拖出、桌面图形客户端、串口设备访问与定时 SFTP 同步。

Authenticated, shared-instance Web access. Computer folders require browser permission and NAS folders require App Center authorization. Native desktop integration, serial devices and scheduled SFTP sync are unavailable.
