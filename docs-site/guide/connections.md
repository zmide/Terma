# 连接管理

连接列表是 Terma 的入口。SSH 与其他协议分开组织，但连接、标签、主机信任和工作区可以互相跳转。

![Terma 连接与工作区](/screenshots/desktop-overview.png)

## SSH 连接

- 支持连接分组、搜索、标签、收藏、最近使用、排序、批量修改和健康检查。
- 支持密码、普通或加密私钥、SSH Agent，以及单级跳板机。
- 可读取用户 `~/.ssh` 和 Terma 运行数据目录中的密钥，并提供 Ed25519 密钥生成与公钥部署向导。
- 首次连接显示 SHA-256 主机指纹；主机密钥变化时提供风险警告。
- 终端、SFTP、隧道和批量命令共用同一份主机信任记录。

## 快速入口

右上角闪电入口或 `Ctrl+K` 可打开快速面板，搜索连接、标签、命名工作区、命令片段和常用操作。连接列表也支持按状态和服务器快速筛选。

## 其他协议

RDP、VNC、XDMCP、FTP/FTPS、Telnet 和串口使用独立活动入口，可以单独分组、搜索和新增。新增 SSH 时还可以按同一主机生成相关协议配置。
