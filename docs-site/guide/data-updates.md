# 数据、更新与迁移

## 数据存储

SQLite 保存连接、转发、设置和任务状态。Terma 支持数据库备份恢复、配置快照和加密迁移包；恢复到另一台机器时可以重新绑定私钥或补充密码，不要求旧机器路径保持一致。

## 配置加密

启用配置加密后，重启时可以查看普通列表和调整非敏感显示设置，但完整编辑连接、保存凭据、恢复数据库和导出敏感迁移包需要先解锁。配置迁移使用独立加密密钥和密码校验值，旧版凭据会在解锁后轮换到当前格式。

## GitHub 更新

桌面端可以检查 GitHub Releases，并按系统、架构和 Windows 安装类型选择更新文件。下载前会比较直连和加速线路，优先使用较快线路；下载后校验 GitHub 提供的 SHA-256，不会静默安装或自动回滚。

更新页也提供对应安装包的 GitHub 原站和五条镜像下载链接，可以选择在系统浏览器中手动下载。手动下载的文件不经过程序内的安装包校验流程。

点击下载链接旁的“测速”可以并行测试六条线路，显示各线路的采样速度并标出最快的一条；不可用线路保留可点击链接，悬停可查看错误或超时原因。测速使用 Terma 所在主机的网络，请求约 256 KB 的安装包样本，每条线路约 8 秒超时，不会保存安装包或启动安装。浏览器与 Terma 主机的代理配置不同时，实际下载速度可能不同。
