# 终端工作区

![Terma 终端工作区](/screenshots/desktop-terminal.png)

## 连接与标签

创建 SSH 连接后，Terma 会在工作区中打开终端标签。终端、SFTP 和转发共用同一份主机信任记录；可以从终端跳转到当前目录的 SFTP，也可以用 `Ctrl+Shift+T` 恢复最近关闭的终端或 SFTP 标签。

## 会话能力

- 多会话 Web 终端，优先使用本地 PTY，不可用时回退到远程 SSH PTY。
- 可保存启动配置，也可只对当前标签临时生效。
- 支持会话保活、恢复最近标签、终端日志和交互延迟显示。
- 支持同步组，在多个终端中同步输入；多行和危险命令会额外确认。
- 支持 ZMODEM `sz` 下载、`rz` 上传，以及拖入本机文件到当前远端目录。

## SSH 图形应用与 X11

X11 转发让你可以在 SSH 终端里启动远端的图形程序，并把窗口显示到本机桌面。它和远程桌面不同：这里只转发被选中的应用窗口，不会接管完整的远端桌面。

- 在 SSH 连接设置中打开 X11 转发；连接后可以从终端启动远端终端、文件管理器、浏览器或其他 GUI 程序。
- Terma 会沿用当前连接的主机信任、跳板机和认证设置，并在启动前检查 `DISPLAY`、`xauth` 与本机图形组件。
- Windows 桌面端使用随包 X Server，macOS 使用 XQuartz，Linux 使用当前图形会话或 Xephyr；缺少组件时，连接页会给出安装或手动配置入口。
- X11 适合运行单个图形工具或短时维护任务；需要完整桌面、窗口管理器或多应用协同时，请使用 [远程桌面与 X11](/guide/remote-desktop.html) 中的 RDP、VNC 或 XDMCP。
- X11 通道会暴露更多图形和剪贴板能力，只应通过可信网络、VPN 或跳板机使用，不要把 X11 或 SSH 端口直接暴露到公网。

## 快速命令

右上角闪电入口或 `Ctrl+K` 可打开全局快速面板，搜索连接、标签、命名工作区、命令片段和常用操作。命令片段支持变量、收藏、导入导出，以及“插入终端”或确认后批量执行。

## 排查连接

连接失败时先检查主机、端口、用户名和认证方式，再确认主机指纹是否发生变化。对需要跳板机、代理或特殊算法的环境，可在连接设置中配置受支持的 SSH 调优参数。
