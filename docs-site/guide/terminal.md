## 连接与标签

创建 SSH 连接后，Terma 会在工作区中打开终端标签。终端、SFTP 和转发共用同一份主机信任记录；可以从终端跳转到当前目录的 SFTP，也可以用 `Ctrl+Shift+T` 恢复最近关闭的终端或 SFTP 标签。

## 会话能力

- 多会话 Web 终端，优先使用本地 PTY，不可用时回退到远程 SSH PTY。
- 可保存启动配置，也可只对当前标签临时生效。
- 支持会话保活、恢复最近标签、终端日志和交互延迟显示。
- 支持同步组，在多个终端中同步输入；多行和危险命令会额外确认。
- 支持 ZMODEM `sz` 下载、`rz` 上传，以及拖入本机文件到当前远端目录。
- 移动端快捷键栏位于终端底部、命令输入框上方，提供 Esc、Tab、Home、End、PgUp、PgDn、方向键和 Ctrl 组合键；可从工具栏显示或隐藏。
- 移动端在返回按钮同一行显示已打开的标签，标签与返回按钮高度一致，可横向滑动切换；返回连接列表后，顶部仍显示这些标签，点击即可回到原有会话。未固定、可关闭的标签始终显示“×”并保留方便触控的点击区域，关闭已连接的会话时仍会要求确认。
- 移动端终端工具栏使用紧凑图标按钮，支持左右滑动；字号按“− 当前字号 +”排列。

## 自定义快捷键

在终端工具栏打开全局设置，选择“快捷键”。可添加普通按键、方向键、Home/End、PgUp/PgDn、F1-F12、自定义 ASCII 字符和支持的 Ctrl/Alt/Shift 组合，并修改按钮名称、启用状态和顺序，或删除不需要的项。最多保存 48 项，按钮名称最多 24 个字符。

修改只在点击保存后生效，取消不改变现有配置；保存后所有已打开的终端快捷键栏立即更新，无需重连。配置保存在 Terma 全局运行设置中，桌面与 Web 共用。快捷键发送到对应终端，不修改应用本身的键盘快捷键；命令和多行脚本仍使用快速命令栏。

## SSH 图形应用与 X11

X11 转发让你可以在 SSH 终端里启动远端的图形程序，并把窗口显示到本机桌面。它和远程桌面不同：这里只转发被选中的应用窗口，不会接管完整的远端桌面。

- 在 SSH 连接设置中打开 X11 转发；连接后可以从终端启动远端终端、文件管理器、浏览器或其他 GUI 程序。
- Terma 会沿用当前连接的主机信任、跳板机和认证设置，并在启动前检查 `DISPLAY`、`xauth` 与本机图形组件。
- Windows 桌面端使用随包 X Server，macOS 使用 XQuartz，Linux 使用当前图形会话或 Xephyr；缺少组件时，连接页会给出安装或手动配置入口。
- X11 适合运行单个图形工具或短时维护任务；需要完整桌面、窗口管理器或多应用协同时，请使用 [远程桌面与 X11](/guide/remote-desktop.html) 中的 RDP、VNC 或 XDMCP。
- X11 通道会暴露更多图形和剪贴板能力，只应通过可信网络、VPN 或跳板机使用，不要把 X11 或 SSH 端口直接暴露到公网。

## 快速命令

右上角闪电入口或 `Ctrl+K` 可打开全局快速面板，搜索连接、标签、命名工作区、命令片段和常用操作。命令片段支持变量、收藏、导入导出，以及“插入终端”或确认后批量执行。

## 排查连接

连接失败时先检查主机、端口、用户名和认证方式，再确认主机指纹是否发生变化。对需要跳板机、代理或特殊算法的环境，可在连接设置中配置受支持的 SSH 调优参数。

## 多功能面板

![多功能面板与本机桌面终端](/screenshots/desktop-terminal-panel.png?v=20261127)

终端工具栏原快速命令栏入口打开工作区共用的多功能面板。四种工具默认以文字和选中下划线显示，每种只保留一个标签，无需新建。拖到工作区右边缘即可移入右侧栏，同时从底部移出；关闭侧栏标签会将它放回底部，终端进程和浏览位置持续保留。底部与右侧可同时使用，窄屏按上下排列。

面板不再另占一行标题栏，布局、停靠、最大化和关闭等控件位于标签栏最右侧；窄窗格将部分操作收入更多菜单。拖动标签可排序、移入其他窗格，或拖到内容区四边分屏。两侧可独立调整尺寸和最大化，底部可收至标签栏。布局预设按钮可以保存、重命名、删除或设为默认；恢复预设保留已有工具会话。

- 快捷命令沿用命令片段的插入、执行和确认规则。快捷命令、SFTP 和主机性能默认跟随当前主工作区的 SSH 终端，不再占用一行选择目标。
- SFTP 复用主 SFTP 的文件浏览、上传下载、编辑、预览、复制移动、重命名、权限和任务入口，窄窗格将文件操作收进更多菜单。使用 Shell 的 OSC 7 回报，或完整提示符中经服务器确认的路径，不根据正在键入的 `cd` 推测路径。可以暂停跟随、手动浏览或返回当前目录。内置 SSH 的 macOS 登录 zsh 会补充当前目录回报，不修改用户 Shell 配置；其他无法确认路径的自定义提示符保留最近浏览位置。
- “终端”运行 Terma 所在桌面电脑的 Shell，显示时自动创建默认会话：Windows 使用 PowerShell，Linux／macOS 使用系统 Shell。新建下拉菜单根据本机已安装的 Shell 提供入口，Windows 支持选择管理员启动。只有一个会话时在工具栏显示 Shell 名称，多个会话时使用右侧实例列表切换；支持拆分和拖动分隔线调整比例。隐藏、移动和恢复预设保留会话，关闭运行中的实例需确认。浏览器和 NAS Web 入口不提供宿主机终端。
- 主机性能支持 Linux 和 macOS，打开后自动每两秒读取 CPU、内存、负载及进程名、PID、CPU 和内存。进程 CPU 使用 `ps` 提供的平均占用；可按 CPU 或内存排序，不显示完整命令行，也不提供结束进程操作。
- 性能窗格沿用连接共享采样。隐藏、收至标签栏、切换到不可见标签或浏览器转到后台时停止对应请求；断线后保留最近采样及时间。其他系统显示当前不支持。

预设只保存布局和工具类型，不保存终端正文、命令、凭据或性能历史。恢复布局后，终端工具首次可见时启动默认 Shell，当前可见的性能窗格自动采样。性能需要已保存的 Linux 或 macOS SSH 连接，临时连接会提示先保存。Windows 管理员启动需经过系统 UAC 确认。
