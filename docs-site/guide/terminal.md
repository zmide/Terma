# 终端工作区

![Terma 终端工作区](/screenshots/desktop-terminal.png)

## 连接与标签

创建 SSH 连接后，Terma 会在工作区中打开终端标签。终端、SFTP 和转发共用同一份主机信任记录；可以从终端跳转到当前目录的 SFTP，也可以用 `Ctrl+Shift+T` 恢复最近关闭的终端或 SFTP 标签。

## 会话能力

- 多会话 Web 终端，优先使用本地 PTY，不可用时回退到远程 SSH PTY。
- 可保存启动配置，也可只对当前标签临时生效。
- 支持会话保活、恢复最近标签、终端日志和交互延迟显示。
- 支持同步组，在多个终端中同步输入；多行和危险命令会额外确认。
- 支持 ZMODEM `sz` 下载、`rz` 上传，以及拖入本机文件到当前远端目录。

## 快速命令

右上角闪电入口或 `Ctrl+K` 可打开全局快速面板，搜索连接、标签、命名工作区、命令片段和常用操作。命令片段支持变量、收藏、导入导出，以及“插入终端”或确认后批量执行。

## 排查连接

连接失败时先检查主机、端口、用户名和认证方式，再确认主机指纹是否发生变化。对需要跳板机、代理或特殊算法的环境，可在连接设置中配置受支持的 SSH 调优参数。
