# 产品简介

Terma 是一个面向桌面端和自托管 Web 的远程连接工作台。它把 SSH 连接、终端、SFTP、远程桌面、端口转发和批量运维放进一个多标签工作区。

## 适合谁

- 需要同时维护多台 Linux 或 Windows 主机的开发者和运维人员。
- 希望把连接配置、终端标签和文件操作放在同一工作区的团队。
- 需要在桌面端、浏览器或局域网设备之间切换的个人用户。

## 核心能力

### SSH 与连接管理

支持密码、普通或加密私钥、SSH Agent 和单级跳板机。连接可分组、搜索、收藏、排序并执行健康检查；首次连接会显示 SHA-256 主机指纹供确认。

### 多协议工作区

除 SSH 外，还可管理 SFTP、FTP/FTPS、RDP、VNC、X11/XDMCP、Telnet、串口和端口转发。不同协议使用独立入口，但可以围绕同一台服务器组织标签。

### 一套数据，多种入口

桌面端是 Electron 对 Web UI 和 Node.js 服务的容器，浏览器和移动端 Web 使用相同的数据结构与连接能力。
