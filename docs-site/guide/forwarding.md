# 转发与批量运维

![Terma 转发列表](/screenshots/desktop-forwarding.png)

## SSH 转发

支持本地转发 `-L`、远程转发 `-R` 和 SOCKS5 动态代理 `-D`。每条规则可以独立启停，并支持模板、URL 路径、自动重连和启动恢复。

转发列表可跨全部 SSH 连接集中管理，支持搜索、状态和服务器筛选、分组标题冻结、拖动排序，以及直接新增、编辑、删除和访问。常用操作可复制本地地址、代理地址和目标地址，并快速测试连通性。

## 批量命令

批量命令可以选择多台主机执行，支持命令模板和 TXT/JSON 结果导出。多行命令、危险命令和隐藏输入会额外确认或自动暂停，避免误操作扩散到整组服务器。

## 使用建议

生产环境先用单台主机验证转发和命令，再扩大到连接组。不要把管理端口、数据库端口或内部服务直接暴露到公网。
