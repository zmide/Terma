# SFTP 文件管理

![Terma 终端与 SFTP 分屏工作区](/screenshots/desktop-terminal-sftp-split.png)

Terma 内置的是基于 SSH 的 SFTP 文件工作区。如果你习惯 Xftp，可以把这里理解为“终端旁边的 Xftp 类文件面板”：终端和文件可以在同一工作区分屏查看，远端数据仍通过 SSH/SFTP 传输，不需要额外安装 Xftp。

## 浏览与搜索

- 支持目录浏览、面包屑导航、分页、多选、收藏、排序和按需递归搜索。
- `Ctrl+F` 打开当前 SFTP 标签的搜索面板；搜索过程中会显示加载状态，按 `Esc` 可关闭搜索。
- 大目录使用远端分页和批量元数据读取，避免一次性拉取全部条目；搜索结果带路径信息，便于直接定位文件。
- 切换回已经打开的目录时会复用短期快照，不重复读取；显式重新打开仍会检查连接并刷新内容。

## 在线编辑

- 文本文件可以在内置编辑器中打开，支持完整编辑器、轻量分段编辑和自动模式；超出设置上限或识别为二进制时会明确提示。
- 编辑器支持语法高亮、自动换行、Tab 缩进、`Ctrl+S`、实时大小/行数统计和未保存关闭确认。
- 文件名编码与文本内容编码分开设置，支持 UTF-8、GB18030/GBK、Big5、Shift_JIS、EUC-KR 等常见编码；保存时尽量保持原始编码。
- 可选择 LF、CRLF 或 CR；Shell 脚本默认保持 Unix LF，选择其他换行格式时会提示兼容性影响。
- 保存前会重新检查远端文件是否变化；发生冲突时可打开左右差异视图，再选择备份覆盖、另存为或暂不保存。
- 覆盖前可保留远端原文件，内部编辑器保留最近 10 个备份版本供比较。

## 图片与 SVG 预览

- 图片文件使用二进制响应预览，支持 PNG、JPEG、GIF、WebP、BMP、ICO 和 SVG。
- SVG 会按图片预览入口打开，不会被当作普通文本强制执行；需要修改 SVG 源码时可以在右键菜单选择“以文本打开”。
- 图片预览与文本编辑入口按文件类型分开，避免把二进制内容误写进编辑器或终端日志。

## 文件传输

- 支持同一主机内复制和移动。
- 支持两台 SSH 主机之间直接流式复制。
- 本地文件或文件夹可直接拖入终端当前目录，也可拖到 SFTP 面板上传。
- SFTP 远端项目可拖到终端或另一个 SFTP 标签。
- 同名项目可选择覆盖、自动改名或取消。

## 分屏与任务

- 终端、SFTP 和本地文件标签支持新标签、上/下/左/右分屏；每个分屏保留独立路径、分页和选择状态。
- 工作区任务中心统一显示上传、下载、目录同步、压缩和跨主机复制进度，任务支持取消、失败重试和结果导出。
- 普通传输和跨主机传输支持持久检查点、暂停、继续和程序重启恢复；浏览器下载支持 HTTP Range。

工作区任务中心会显示 SFTP 传输和目录同步进度；长任务可在不中断连接的情况下继续观察。
