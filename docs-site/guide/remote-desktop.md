# 远程桌面与 X11

![Terma 远程桌面工作区](/screenshots/desktop-remote.png)

Terma 将远程图形能力分成远程桌面协议和 SSH 图形转发两类，按平台选择合适的客户端。

## VNC

VNC 自动模式默认使用随包提供的 TigerVNC Viewer；如果它不可用或启动失败，再回退到系统客户端。内置 noVNC 不会被自动切换，只能在连接设置中手动选择。三种方式都可以单独选择；工作区支持重连、全屏和双向文本剪贴板同步。

显示尺寸取决于客户端和远端服务：内置 noVNC 可以把画面缩放到当前窗口；TigerVNC 没有客户端缩放，只能通过 `RemoteResize` 请求远端桌面跟随窗口。若服务端不支持动态调整分辨率，TigerVNC 会显示滚动条，这是 VNC 协议能力限制，不是 Terma 页面溢出。需要始终铺满窗口时请选择“内置 noVNC”；需要保持原始像素时请选择“原始像素”。

### 中文剪贴板

TigerVNC Viewer 的文本剪贴板由远端 VNC 服务端提供。连接到 `x11vnc` 或 `wayvnc` 这类共享已有桌面的服务时，服务端可能把中文暴露成 `\\uXXXX` 或乱码；这是服务端剪贴板编码问题，无法靠 Viewer 参数修复。探测到共享桌面时，Terma 只在界面提醒，不会自动替换你选择的客户端。

需要可靠中文双向复制时，推荐在远端启用独立的 TigerVNC/Xvnc 虚拟桌面；如果必须共享当前物理桌面，可在连接设置手动选择 Terma 内置 noVNC，并关联 SSH 剪贴板辅助。Linux 辅助通道需要远端安装 `xclip`、`xsel` 或 `wl-clipboard`。TigerVNC 原生 Viewer 仍主要适合文本剪贴板，图片同步请使用内置 noVNC 的辅助通道。

## RDP、X11 与 XDMCP

- RDP 使用系统原生客户端。
- Windows 桌面包内置并管理 X Server；macOS 使用 XQuartz；Linux 复用当前图形桌面并使用 Xephyr。
- XDMCP 支持直接查询、间接查询和局域网广播，但协议本身不加密，只应在可信局域网使用。
- 远端桌面安装、卸载和修复操作会显示任务进度，管理员凭据只用于当前操作，不会保存。

## 使用建议

远程桌面通常比纯 SSH 暴露更大的攻击面。优先通过私有网络、跳板机或 VPN 访问，不要直接把 VNC、XDMCP 端口暴露到公网。
