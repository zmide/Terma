# 常见问题

## 浏览器打不开 Web 模式

先在服务器执行 `curl -I http://127.0.0.1:8088/`，确认 Terma 本身已启动；再检查宝塔站点的反向代理、HTTPS 证书和 WebSocket 开关。

## SSH 能连接但终端没有输入输出

检查远端 shell、PTY 分配和连接保活设置。若使用跳板机或受限 shell，先在系统终端用同一用户和密钥验证 SSH，再回到 Terma 检查连接配置。

## VNC 提示密码错误

确认 VNC 密码与远端 VNC 服务配置一致。TigerVNC、noVNC 和系统客户端可能使用不同的认证入口；可在连接时重新输入密码，并选择是否更新保存的凭据。

## 如何报告问题

提交 Issue 时请提供 Terma 版本、操作系统、复现步骤和脱敏日志。不要上传私钥、访问 Token、密码、完整邮件日志或数据库备份。
